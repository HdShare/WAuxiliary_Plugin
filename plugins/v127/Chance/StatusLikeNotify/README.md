# 状态通知与自动点赞

版本：**5.2.0**  
作者：**Chance**  
更新日期：**2026-10-18**

插件定时检查指定好友最近 24 小时内的微信状态，并根据两份独立名单执行自动点赞或发送通知。

## 功能概览

- **自动点赞**：发现点赞名单中的好友发布新状态后，先检查是否已经点赞；确认未点赞后按随机延时提交，并在提交后复核结果。
- **状态通知**：发现通知名单中的好友发布新状态后，发送系统通知和 Toast 提醒。
- **独立名单**：点赞名单和通知名单分别管理、分别生效，同一好友可以同时加入两份名单。
- **轮询检查**：按设定间隔检查好友最近 24 小时内的最新状态。
- **限流控制**：限制点赞间隔、每小时点赞次数和通知频率，降低重复请求和提醒过密的情况。
- **日志管理**：支持查看最近日志、清空日志和设置自动清理周期。

## 启用与入口

1. 在插件列表中手动启用插件。
2. 通过插件设置页或微信消息长按菜单打开插件菜单。
3. 插件加载后会自动开始轮询，不会自动启用自己。

当前消息菜单入口名称为“状态监控”。系统通知功能需要授予相应通知权限。

## 主菜单

主菜单提供以下操作：

- **自动点赞**：开启或关闭自动点赞。
- **通知设置**：管理自动通知、系统通知和 Toast 提醒。
- **轮询间隔**：设置状态检查间隔，最小为 30 秒。
- **点赞随机延时**：设置发现新状态后提交点赞前的随机等待时间。
- **名单设置**：分别编辑点赞名单和通知名单。
- **查看运行状态**：查看微信版本、轮询状态、名单数量、最近操作时间、通知统计、点赞统计和最近错误。
- **查看/清空日志**：查看最近 50 条日志、清空日志或设置定时清理。
- **恢复默认设置**：恢复开关、轮询、延时和限流参数，名单会保留。

## 默认设置

| 设置 | 默认值 | 说明 |
| --- | --- | --- |
| 自动点赞 | 开 | 控制点赞名单的自动点赞 |
| 自动通知 | 开 | 控制通知名单的提醒 |
| 系统通知 | 开 | 发送系统通知栏提醒 |
| Toast 提醒 | 开 | 微信在前台时显示 Toast |
| 轮询间隔 | 300 秒 | 最小 30 秒 |
| 点赞随机延时 | 5～30 秒 | 发现新状态后随机等待 |
| 点赞最小间隔 | 30 秒 | 限制连续点赞请求 |
| 每小时点赞上限 | 20 次 | 限制一小时内的点赞请求数量 |
| 通知最小间隔 | 5 秒 | 限制通知发送频率 |
| 日志定时清理 | 关闭 | 输入小时数，0 表示关闭 |

## 名单管理

点赞名单和通知名单都支持：

- 查看当前名单成员；
- 搜索好友并多选添加或移除；
- 按微信标签批量设置；
- 清空名单。

搜索支持备注、昵称、显示名称、微信号和 wxid。搜索结果会显示好友名称和 wxid；已经加入当前名单的好友会标记为“（已添加）”。

在“查看名单”中，当前成员默认全部选中，取消勾选后确认即可移除对应成员。按标签设置时，标签成员默认全部选中，取消勾选的成员不会保留在当前名单中。

名单保存在插件配置中，修改或重新加载插件不会清空名单。

## 运行流程

1. 插件合并两份名单并去重，逐个读取好友最近 24 小时内的最新微信状态。
2. 通知名单发现新的状态后，按好友和状态 ID 去重，再进入通知队列。
3. 点赞名单发现新的状态后，先查询点赞状态：
   - 已点赞：记录跳过，不再发送请求；
   - 未点赞：进入随机延时队列；
   - 无法判定：本轮不发送，等待后续检查。
4. 延时结束后再次确认开关、名单、状态 ID和点赞状态。
5. 点赞请求提交后最多复核三次，只有复核确认已点赞才计为成功。
6. 通知和点赞都会受到对应的间隔与数量限制，达到限制时自动延后处理。

## 日志与统计

运行日志文件为插件目录下的 `run.log`。日志菜单支持查看最近 50 条记录、清空日志和设置按小时自动清理。

清理日志时会保留通知记录。运行状态中的点赞成功和失败次数从当前日志统计：

- “微信原生点赞已确认”计为成功；
- 请求未提交、请求异常、结果未知和复核异常计为失败；
- 仅提交到微信队列不计为成功。

## 兼容性与限制

插件使用公开接口和微信内部状态接口。当前代码已针对微信 **8.0.79**、`versionCode 3200` 完成取证；其它微信版本未完成验证，升级微信后可能需要重新适配。

状态数据来自微信本地缓存，好友发布后何时同步到本机取决于微信自身。微信进程被系统停止后，轮询、自动点赞、通知和日志清理都会停止。

自动点赞依赖微信内部接口，可能受到微信版本变化和账号风控策略影响。提交请求被微信接受不代表点赞已经完成，插件只有在后续状态查询确认成功后才记录为成功。
