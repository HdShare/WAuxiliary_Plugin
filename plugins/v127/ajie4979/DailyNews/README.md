# 每日60S新闻 WAuxiliary 插件

支持微信群每日60S新闻文本/图片手动推送、推送群管理、每日定时推送，以及漏推补发与调试日志。

## 安装

1. 将整个 `每日60S新闻` 文件夹复制到 WAuxiliary 插件目录
2. 在插件列表中启用 **每日60S新闻**
3. 打开微信前台界面一次，确保插件完成初始化
4. 输入 `/每日新闻设置` 并点击发送，打开配置界面

> 说明：插件文件夹名为 `每日60S新闻`，插件内部 ID 仍为 `DailyNews`（兼容已有配置）。

## 常用指令

### 输入框发送（仅宿主可触发，会拦截发送）

- `/每日新闻设置`：打开独立配置界面
- `/每日新闻` / `/每日新闻发送`：立即向当前聊天发送新闻
- `/每日新闻测试接口`：请求新闻接口并 toast 返回结果

> 安全说明：以上指令只在宿主微信输入框点击发送时生效；群内其他人发送同名内容不会触发，避免误触/刷屏。

其余配置请在 **/每日新闻设置** 界面操作。

## 配置界面能力

- 发送模式：文本早报 / 新闻图片
- 定时发送：开关、时间（`HH:mm`）、启用/删除定时
- 推送群管理：添加当前群、移除当前群、清空列表
- 状态显示：当前模式、定时状态、今日是否已推送（支持部分成功 x/y）、上次成功时间、推送群数
- 定时推送测试：立即向当前群发送（验证发送链路）
- 调试：开启调试日志、测试接口

## 配置键

- `daily.news.send.mode`：发送模式，`text` 或 `image`
- `daily.news.schedule.time`：定时发送时间，默认 `08:00`
- `daily.news.schedule.enabled`：定时开关
- `daily.news.group.list`：群列表，多个群以 `;;` 拼接
- `daily.news.tasks`：任务持久化记录
- `daily.news.debug.enabled`：调试日志开关，默认 `false`
- `daily.news.last.success.date`：最近一次全部成功推送日期（`yyyy-MM-dd`）
- `daily.news.last.success.time`：最近一次全部成功推送时间
- `daily.news.last.attempt.date`：最近一次尝试推送日期
- `daily.news.success.groups`：今日已成功推送的群（`yyyy-MM-dd|群ID;;群ID`）

## 定时与补发说明

- 使用系统闹钟做每日定时（优先精确闹钟）
- 插件加载时会重挂闹钟，并检查是否需要补发
- 若今天已到点但尚未完成全部目标群推送，会自动补发/续推（含刚到点场景）
- 按群记录成功：已成功的群不会重复发，失败群后续可补
- 全部目标群成功后才记“今日已推送”
- 定时与补发互斥执行，降低并发重复推送
- 图片模式失败时会尝试回退为文本发送

## 调试日志

1. 打开 `/每日新闻设置`
2. 开启 **调试日志**
3. 保存设置
4. 正常操作插件（加载、发送、定时、测试等）
5. 在 WAuxiliary 宿主日志中查看输出

日志格式示例：

```text
[每日60S新闻][信息][加载] 步骤1/4：插件开始加载
[每日60S新闻][信息][定时] 步骤1/5：开始挂载每日定时
[每日60S新闻][信息][补发] 检测到今日未完成推送（迟到120秒），准备补发/续推
[每日60S新闻][信息][新闻推送] 步骤2/5：开始请求新闻接口
```

说明：

- 只有开启调试日志时才会调用宿主 `log()`
- 不再生成 `daily_news_log.txt` 文件
- 覆盖加载、指令、设置、群管理、定时、补发、推送、接口测试等流程

## 缓存位置

优先目录：

`/storage/emulated/0/Android/media/com.tencent.mm/WAuxiliary/Plugin/每日60S新闻`

不可写时回退到宿主 `cacheDir/每日60S新闻`。

用于图片下载等临时缓存，不写操作日志文件。

## 使用建议

1. 先在群聊中打开设置，添加需要推送的群
2. 选择文本或图片模式
3. 设置每日时间并启用定时
4. 建议先用“定时推送测试 / 测试接口”确认链路正常
5. 排查问题时再临时打开调试日志，并查看宿主日志
