# 📱 微信聊天记录提取插件 · 使用指南

> 🔧 **v1.3** · 基于 WAuxiliary 1.2.7.r1454（代号 1454）

这是一个基于 WAuxiliary 框架开发的微信聊天记录本地备份工具。支持**智能增量备份（只提新增）**、**指定数量提取**、**全量备份**，并支持导出 **TXT、AI (TSV)** 两种格式。

---

## 🚀 快速上手 (核心指令)

在微信任意聊天窗口的输入框内，输入以下指令并点击**发送**，插件会自动拦截发送动作并执行提取，不会将指令发给对方。

| 输入指令 | 导出格式 | 运行逻辑 (默认模式) |
| :--- | :--- | :--- |
| **`/提取`** | **TXT** (默认) | **智能模式**：优先提取**新增记录**；若无新增，则自动提取**全部记录**。 |
| **`/提取 ai`** | **AI 数据** | **智能模式**：优先提取**新增记录**；若无新增，则自动提取**全部记录**。 |

---

## 🛠️ 进阶参数组合 (自由搭配)

指令支持 **[数量]** 和 **[格式]** 自由组合，参数顺序不限，用**空格**隔开即可。

### 1. 按“导出范围”提取
*   **强制只提新增**：`/提取 新增`（仅导出上一次备份之后产生的新消息，无新消息则不生成文件）。
*   **强制导出全部**：`/提取 全部`（不管之前有没有提取过，直接全量导出）。
*   **提取指定数量**：`/提取 100`（仅提取最近的 100 条聊天记录）。

### 2. 混合搭配示例
*   `/提取 新增 ai` —— 仅提取最新的聊天记录，并保存为 AI 专用 `.tsv` 格式。

---

## 📂 导出文件与路径

*   **保存目录**：手机内部存储的 `/Documents/WA/` 文件夹。
*   **命名规则**：`[对方微信备注或昵称]_[当前系统时间].后缀`
    > 📌 *例如：在 2026年7月14日 8点48分56秒 导出与「张三」的聊天，文件名将为：*
    > `张三_2026年7月14日8点48分56秒.txt` (使用 ai 格式时后缀为 `.tsv`)

## 🎨 导出格式效果对比

### 1. 📝 TXT 格式 (经典纯文本)
*   **适用场景**：最纯粹的文本备份，体积极小，最方便后期在电脑上进行关键字全局搜索。
*   **排版细节**：
    ```text
    [2026年7月14日8:48:56] 张三:
    [引用 2026年7月14日8:48:00 李四]: 下班后一起去吃火锅吗？
    行啊，我准时到！
    ```

### 2. 🤖 AI 格式 (TSV 数据，大模型专用)
*   **适用场景**：**准备喂给 ChatGPT、Claude、DeepSeek 等大模型，进行年度回忆、总结或情感分析。**
*   **文件后缀**：`.tsv`
*   **排版细节**：`时间\t发送者\t内容` Tab 分隔，极限省 token，模型对表格数据精准度极高：
    ```
    2026年7月14日8:48:56	张三	下班后一起去吃火锅吗？
    2026年7月14日8:49:02	李四	好啊，老地方见！
    ```

## ❓ 常见问题

*   **Q：为什么输入 `/提取 新增` 却导出了 100 条？**
    *   **A**：如果是**第一次**对该好友使用新增提取，插件由于本地尚无该好友的历史导出时间戳，会默认先导出最近的 100 条建立基础底包，之后再次使用时，就会完全转为纯粹的增量（仅导出新发送的消息）。
*   **Q：为什么导出的 AI 格式后缀是 `.tsv`？**
    *   **A**：`TSV` 格式用 Tab 分隔 `时间  发送者  内容`，无任何 JSON/CSV 语法符号，极限降低 Token 消耗，且模型对表格数据分析精准度极高。
